---
title: "Contributing"
---

Contributions are welcome – bug reports, documentation improvements, and code changes.

## Where to start

- Report issues: https://github.com/Supervertaler/Supervertaler-Workbench/issues
- Questions / discussion: https://github.com/orgs/Supervertaler/discussions

## Documentation edits

These help pages live in their own repository, [Supervertaler/supervertaler-help](https://github.com/Supervertaler/supervertaler-help). If you spot missing or unclear documentation, open an issue or submit a pull request there.

## Tip

When reporting a bug, include:

- Your OS
- Your Supervertaler version
- Steps to reproduce
- Any error message text
