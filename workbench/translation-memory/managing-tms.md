---
title: "Creating & Managing TMs"
---

Translation Memories (TMs) help you reuse past translations.

## Add or create a TM

1. Open the **💾 TMs** tab
2. Add an existing TM (for example with **📥 Import TMX**) or create a new one with **+ Create New TM**. TM names must be unique; if the name you type is already taken, Supervertaler says so.
3. Enable **Read** to use it for matches
4. Enable **Write** if you want new translations saved into it

:::note
**Read** is set per project, and a new project starts with every TM switched off, so a new job doesn't quietly pick up the last job's TMs. Tick **Read** for the TMs you want in each project. If no TM is switched on, the log says so. (A TM you create with **+ Create New TM** is switched on for the open project straight away.)
:::

## Using TM matches

- TM matches appear automatically as you navigate.
- You can insert matches quickly:
	- **Ctrl+Space** inserts the currently selected match
	- Double-click a match in the panel to insert it

## Tips

- Keep separate TMs per client or domain if needed.
- Ensure the TM language pair matches your project.
- If the match panel stays empty, see [TM Matches Not Appearing](/workbench/troubleshooting/tm-matches/).
- If a segment contains tags/placeholders, keep them intact when inserting a match.
