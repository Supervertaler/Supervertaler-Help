## Summary

- Supervertaler does **not** collect, store, or transmit your translations, termbases, or documents to Supervertaler servers
- Your translations, termbases, and documents stay on your machine
- When you use AI features, data is sent directly to the AI provider **you** selected, using your own API key
- **Claude's prompt cache** (from v18/19.20.208) – with Claude, directly or through OpenRouter, Translate active segment (Alt+T) and Chat keep the part of a request that is the same every time ready for the next one. Anthropic holds that cached part – your document and memory bank among it – for up to an hour after the last use, where it was five minutes. It is kept for your account only and is not shared with anyone else. See [Prompt caching](/trados/ai-cost-guide/#prompt-caching).
- **Anonymous usage statistics** – on by default, and one click turns them off (**Settings → General → Privacy**). A single ping on startup sends a random anonymous ID, the plugin, Trados and Windows versions, your system locale and a few display and hardware details. No personal data, no translation content. See [Usage Statistics](/trados/settings/usage-statistics/) for the full list.
- **Trial registration** (v18/19.20.118+) – trial installs register the trial's start date with a first-party licence endpoint on startup, so the trial behaves consistently across reinstalls. Only the anonymous machine hash, plugin/Studio version, locale, and the trial's start date are sent – no content, no personal data. This is part of how the trial functions (like licence validation) and is separate from the usage statistics. *(From v18/19.20.210)* With the usage statistics switched on, it also says how many AI requests this trial has made (a number up to 100) and the day of the first, and it is sent once more after the first AI request of a Studio session. That shows whether new users get as far as using the AI. No text, project, file or model is sent, and with the usage statistics off, nothing about AI requests is sent. See the [full privacy policy](https://supervertaler.com/privacy/) for details.
- For maximum confidentiality with AI features, use [Ollama](https://ollama.com) – all processing stays local
- Source code is publicly available on [GitHub](https://github.com/Supervertaler/Supervertaler-for-Trados) for independent verification
